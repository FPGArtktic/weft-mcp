# seven_seg_decoder

Generated by WEFT 0.5.0 from the project's sources, constraints and reports. Regenerate it rather than editing it.

hexadecimal digit to seven-segment patterns

Outputs are active low, as a common-anode display needs. The patterns are held active high internally and inverted once on the way out, which keeps the table readable.

Deliberately written in VHDL: the rest of the design is SystemVerilog and Verilog-2001, so this entity is what forces the toolchain to parse and elaborate across language boundaries.

Defined in `counter/src/seven_seg_decoder.vhd:19` (vhdl).
