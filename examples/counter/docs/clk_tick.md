# clk_tick

Generated by WEFT 0.5.0 from the project's sources, constraints and reports. Regenerate it rather than editing it.

clock divider emitting a one-cycle tick at TICK_HZ

Deliberately plain Verilog-2001: no logic, no always_ff, no $clog2. The rest of the design is SystemVerilog and VHDL, so this file is what proves the toolchain copes with all three languages in one hierarchy.

DIVISOR is declared as a vector so that WIDTH bits can be sliced out of it. Verilog-2001 has no '() cast, and without the narrowing the comparison would mix a WIDTH-bit counter with a 32-bit integer.

Defined in `counter/src/clk_tick.v:20` (verilog).
