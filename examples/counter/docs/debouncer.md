# debouncer

Generated by WEFT 0.5.0 from the project's sources, constraints and reports. Regenerate it rather than editing it.

input synchroniser, contact debouncer and edge detector

Two flip-flops bring @noisy_in into the clock domain first; only then does the stability counter run, so metastability never reaches it. Any bounce restarts the count, which is why a burst of chatter costs one @STABLE_MS window rather than one per edge.

Defined in `counter/src/debouncer.sv:19` (systemverilog).
